# FastBreak — Forge 1.8.9 (работает с LabyMod)

Ускоряет ломание блоков. Режим **Polar** — осторожный пресет для HvH-серверов с античитом Polar.
Миксинов и коремодов нет: мод работает через рефлексию полей `PlayerControllerMP`, поэтому
не конфликтует с LabyMod, OptiFine и прочими модами.

## Сборка

**Вариант 1 — локально** (нужна JDK 17; JDK 8 Gradle скачает сам):
```
./gradlew build          # Linux / macOS
gradlew.bat build        # Windows
```
Готовый мод: `build/libs/FastBreak-1.8.9.jar` (jar-файлы из `build/intermediates` не нужны).

**Вариант 2 — без установки Java:** залей папку в новый репозиторий на GitHub →
вкладка **Actions** → workflow «Run Gradle Build» → скачай артефакт `mod-jar`.

## Установка
1. Профиль Forge 1.8.9 + LabyMod (LabyMod 3 ставится поверх Forge).
2. Положи `FastBreak-1.8.9.jar` в `.minecraft/mods`.

## Управление
- **G** — включить/выключить (клавиша меняется в «Настройки → Управление → FastBreak»).
- `/fastbreak` или `/fb` — статус и настройки.

| Команда | Что делает |
|---|---|
| `/fb toggle` / `on` / `off` | вкл/выкл |
| `/fb mode polar` | пресет под Polar: порог 0.80 ±0.04, задержка 3 тика (≈20% быстрее) |
| `/fb mode threshold` | ломает при прогрессе ≥ `threshold` |
| `/fb threshold 0.7` | порог для режима threshold (0.05–1.0; 0.7 = на 30% быстрее) |
| `/fb mode multiplier` | скорость ×`multiplier` |
| `/fb multiplier 1.4` | множитель (1–5) |
| `/fb mode max` | **самый быстрый, который принимает обычный сервер**: 70% времени, без задержки между блоками |
| `/fb mode instant` | **мгновенно (1 тик)**: STOP-пакет в тот же тик, что START. Только для серверов без проверки времени |
| `/fb idelay 1` | задержка Instant в тиках: 0 = сразу, 1 = 0.05 с (по умолчанию), 2 = 0.1 с … |
| `/fb nodelay` | убрать ванильную паузу 5 тиков между блоками **всегда**, даже когда FastBreak выключен (по умолчанию вкл) |
| `/fb tools` | ускорять только подходящим инструментом по блокам из его списка (по умолчанию вкл) |
| `/fb list [инструмент]` | показать списки блоков |
| `/fb add <инструмент> [блок]` | добавить блок в список (без блока — тот, на который смотришь) |
| `/fb remove <инструмент> [блок]` | убрать блок из списка |
| `/fb reset [инструмент]` | вернуть списки по умолчанию |
| `/fb delay 1` | задержка между блоками в тиках (ванила 5) для threshold/multiplier |
| `/fb jitter 0.03` | случайный разброс порога, чтобы время ломания не было одинаковым |
| `/fb ground` | ускорять только на земле (по умолчанию вкл) |
| `/fb hud` | надпись справа сверху |

Настройки сохраняются в `.minecraft/config/fastbreak.properties`.

## Как работает
Ванильный клиент каждый тик прибавляет к `curBlockDamageMP` силу удара по блоку и при 1.0 отправляет
`C07 STOP_DESTROY_BLOCK`, после чего 5 тиков ждёт перед следующим блоком. Мод в конце тика поднимает
прогресс до 1.0, как только на следующем тике он дойдёт до порога (время ломания ≈ порог × ванила),
и укорачивает задержку между блоками. Пакеты отправляет ванила в обычном порядке, своих мод не шлёт.

## Только инструментами
С `/fb tools` (включено по умолчанию) FastBreak ускоряет, только если в руке инструмент нужного типа,
блок есть в его списке и инструмент реально эффективен против этого блока. Всё остальное, в том числе рукой
и не тем инструментом, ломается как обычно. Инструменты: `sword`, `pickaxe`, `axe`, `shovel`, `shears`.

| Инструмент | Блоки по умолчанию |
|---|---|
| меч (`sword`) | паутина, листва |
| кирка (`pickaxe`) | камень, булыжник, замшелый булыжник, песчаник, красный песчаник, эндерняк, каменный кирпич, незерак, кирпичи, незер-кирпич, глина (обожжённая и крашеная), кварц, все руды |
| топор (`axe`) | доски, брёвна, книжные полки |
| лопата (`shovel`) | земля, дёрн, песок, гравий, глина, снег, песок душ, мицелий |
| ножницы (`shears`) | шерсть, паутина, листва |

Пример: `/fb add pickaxe obsidian`, или посмотри на блок и введи `/fb add pickaxe`.
Справа сверху у надписи FastBreak горит точка: зелёная, если блок под прицелом будет ломаться быстро, серая — если нет.

## Почему «мгновенно» работает не везде
Ванильный сервер 1.8.9 (и Spigot/Paper) сразу принимает «блок сломан», только если прошло
**≥70%** обычного времени ломания. Если пакет пришёл раньше, блок появится обратно и сломается,
только когда пройдёт полное время. Обойти это с клиента нельзя, проверку делает сервер.

- Сервер не проверяет время (некоторые HvH-сборки) → `/fb mode instant`.
- Обычная серверная логика → `/fb mode max`. В этом режиме блок, у которого за тик набирается ≥35%
  прогресса, ломается за 1 тик. Поэтому с **Эффективностью V + Спешкой II** камень, дерево и земля
  ломаются почти мгновенно.
- Если после instant блоки «возвращаются», значит сервер проверяет время: переключись на `max`.

## Подбор под Polar
Значения пресета — стартовые, на живом Polar не проверены. Если флагает:
`/fb mode threshold`, `/fb threshold 0.85`, `/fb delay 4`, `/fb jitter 0.05` — и поднимай скорость
постепенно, пока не начнёт флагать.
