# FastBreak + Backtrack + Clutch — Forge 1.8.9 (работает с LabyMod)

Ускоряет ломание блоков. Режим **Polar** — осторожный пресет для HvH-серверов с античитом Polar.
Миксинов и коремодов нет: мод работает через рефлексию полей `PlayerControllerMP`, поэтому
не конфликтует с LabyMod, OptiFine и прочими модами.

## Сборка

**Вариант 1 — локально** (нужна JDK 17; JDK 8 Gradle скачает сам):
```
./gradlew build          # Linux / macOS
gradlew.bat build        # Windows
```
Готовый мод: `build/libs/FastBreak-1.8.9.jar` (jar-файлы из `build/intermediates` не нужны).

**Вариант 2 — без установки Java:** залей папку в новый репозиторий на GitHub →
вкладка **Actions** → workflow «Run Gradle Build» → скачай артефакт `mod-jar`.

## Установка
1. Профиль Forge 1.8.9 + LabyMod (LabyMod 3 ставится поверх Forge).
2. Положи `FastBreak-1.8.9.jar` в `.minecraft/mods`.

## Управление
- **G** — включить/выключить (клавиша меняется в «Настройки → Управление → FastBreak»).
- `/fastbreak` или `/fb` — статус и настройки.

| Команда | Что делает |
|---|---|
| `/fb toggle` / `on` / `off` | вкл/выкл |
| `/fb mode polar` | пресет под Polar: порог 0.80 ±0.04, задержка 3 тика (≈20% быстрее) |
| `/fb mode threshold` | ломает при прогрессе ≥ `threshold` |
| `/fb threshold 0.7` | порог для режима threshold (0.05–1.0; 0.7 = на 30% быстрее) |
| `/fb mode multiplier` | скорость ×`multiplier` |
| `/fb multiplier 1.4` | множитель (1–5) |
| `/fb mode max` | **самый быстрый, который принимает обычный сервер**: 70% времени, без задержки между блоками |
| `/fb mode instant` | **мгновенно (1 тик)**: STOP-пакет в тот же тик, что START. Только для серверов без проверки времени |
| `/fb delay 1` | задержка между блоками в тиках (ванила 5) для threshold/multiplier |
| `/fb jitter 0.03` | случайный разброс порога, чтобы время ломания не было одинаковым |
| `/fb ground` | ускорять только на земле (по умолчанию вкл) |
| `/fb hud` | надпись справа сверху |

Настройки сохраняются в `.minecraft/config/fastbreak.properties`.

## Как работает
Ванильный клиент каждый тик прибавляет к `curBlockDamageMP` силу удара по блоку и при 1.0 отправляет
`C07 STOP_DESTROY_BLOCK`, после чего 5 тиков ждёт перед следующим блоком. Мод в конце тика поднимает
прогресс до 1.0, как только на следующем тике он дойдёт до порога (время ломания ≈ порог × ванила),
и укорачивает задержку между блоками. Пакеты отправляет ванила в обычном порядке, своих мод не шлёт.

## Почему «мгновенно» работает не везде
Ванильный сервер 1.8.9 (и Spigot/Paper) сразу принимает «блок сломан», только если прошло
**≥70%** обычного времени ломания. Если пакет пришёл раньше, блок появится обратно и сломается,
только когда пройдёт полное время. Обойти это с клиента нельзя, проверку делает сервер.

- Сервер не проверяет время (некоторые HvH-сборки) → `/fb mode instant`.
- Обычная серверная логика → `/fb mode max`. В этом режиме блок, у которого за тик набирается ≥35%
  прогресса, ломается за 1 тик. Поэтому с **Эффективностью V + Спешкой II** камень, дерево и земля
  ломаются почти мгновенно.
- Если после instant блоки «возвращаются», значит сервер проверяет время: переключись на `max`.

## Подбор под Polar
Значения пресета — стартовые, на живом Polar не проверены. Если флагает:
`/fb mode threshold`, `/fb threshold 0.85`, `/fb delay 4`, `/fb jitter 0.05` — и поднимай скорость
постепенно, пока не начнёт флагать.

# Backtrack

Пока ты в бою с игроком (ударил его за последние `window` мс, и он на дистанции `range`),
мод придерживает входящие пакеты на `delay` мс. Ты видишь цель и бьёшь её в её позиции
`delay` мс назад: когда цель отходит, это работает как бонус к дистанции удара.

- **H** — включить/выключить, `/bt` или `/backtrack` — статус.

| Команда | Что делает |
|---|---|
| `/bt toggle` / `on` / `off` | вкл/выкл |
| `/bt mode polar` | задерживает **все** входящие пакеты одинаково (вместе с transaction/keepalive). Для Polar это выглядит как пинг выше обычного, позиции и транзакции не расходятся. По умолчанию |
| `/bt mode entity` | классика: задерживает только движение сущностей. Эффект сильнее, но Polar видит рассинхрон с transaction |
| `/bt delay 120` | задержка в мс (0–1000) |
| `/bt range 2.5 6` | включаться, только когда цель на этой дистанции |
| `/bt maxhold 500` | дольше этого очередь непрерывно не держится, потом сбрасывается |
| `/bt cooldown 250` | пауза после сброса |
| `/bt window 1000` | сколько мс после твоего удара считаешься «в бою» |
| `/bt hud` | надпись справа сверху (● и число пакетов в очереди, пока держит) |

Очередь сразу сбрасывается при телепорте/сетбеке, респавне, заходе в мир и кике.
Настройки — `.minecraft/config/backtrack.properties`.

**Под Polar:** держи `delay` 80–150 и `maxhold` ≤ 500. Длинная непрерывная задержка выглядит как скачок пинга.
Пока очередь держится, ты сам тоже видишь мир с задержкой (в том числе свой отброс), это нормально.

# Clutch / Scaffold (в стиле Augustus)

Когда тебя сбили в войд или ты падаешь с высоты, мод плавно доворачивается на грань ближайшего блока
и ставит блок под ноги. Повороты **тихие**: на сервер уходит поворот на блок, а камера у тебя остаётся
где была. Блок ставится, только когда реальный рейтрейс с серверного поворота попадает в нужную грань.

- **Тихие повороты** с ограничением скорости и **GCD-фиксом** (шаг поворота кратен чувствительности мыши, как у мышки).
- **MoveFix**: нажатия WASD пересчитываются под серверный yaw, движение совпадает с поворотом. Спринт пропадает сам,
  если серверный поворот смотрит назад, как и у настоящего игрока.
- **Раздельные скорости** для бриджа и клатча (у Augustus это CustomBlockClutchRotationSpeeds).
- **ExtraBlockSearch**: если прямо под ногами не за что зацепиться, ставит соседний блок и строит к себе.
- **Предсказание падения**: целится туда, где ты окажешься через ~1.5 тика.
- **Авто-выбор блоков** (самый большой стак в хотбаре) и возврат слота. Песок/гравий, сундуки и TNT не берёт.
  Не кликает по верстакам, сундукам, печкам и т.п., чтобы не открылся GUI.

- **J** — включить/выключить, `/cl` или `/clutch` — статус.

| Команда | Что делает |
|---|---|
| `/cl toggle` / `on` / `off` | вкл/выкл |
| `/cl mode clutch` | только спасает при падении (по умолчанию) |
| `/cl mode scaffold` | ещё и бриджит: ставит блок, когда под ногами пусто (+ клатч) |
| `/cl speed 35 60` | скорость поворота в °/тик для бриджа |
| `/cl clutchspeed 80 140` | скорость поворота в °/тик при клатче |
| `/cl fall 3` | клатчить, если под тобой пусто на N+ блоков |
| `/cl void` | клатчить только над войдом |
| `/cl search 2` | радиус поиска блоков (0–3) |
| `/cl reach 4.5` | дистанция до грани |
| `/cl switch` | авто-выбор блоков в хотбаре |
| `/cl switchback` | вернуть прежний слот после клатча |
| `/cl noswing` | не махать рукой на клиенте (пакет взмаха уходит) |
| `/cl delay 0` | задержка между блоками, тиков |
| `/cl keep 3` | сколько тиков держать поворот после блока, потом плавный возврат |
| `/cl hud` | надпись справа сверху: число блоков, ● пока работает |

Настройки — `.minecraft/config/clutch.properties`.

**Под Polar:** не ставь `clutchspeed` выше ~150 и `speed` выше ~70, держи `reach` ≤ 4.5. Большие резкие повороты
и постановка «за спину» без поворота — главное, за что ловят скаффолд.
