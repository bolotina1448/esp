# Scaffold — Forge 1.8.9 (работает с LabyMod)

Скаффолд с клатчем в стиле Augustus. Миксинов и коремодов нет, поэтому не конфликтует с LabyMod и OptiFine.

## Скачать
**[Scaffold-1.8.9.jar](https://github.com/bolotina1448/esp/releases/download/scaffold-latest/Scaffold-1.8.9.jar)**.
Положи в `.minecraft/mods` профиля Forge 1.8.9 с LabyMod.

## Что умеет
- **Бридж**: когда под ногами пусто, ставит блок (держит уровень при прыжках, как SameY).
- **Клатч**: если сбили в войд или падаешь с высоты, доворачивается на ближайший блок и ставит блок под ноги.
  Целится туда, где ты окажешься через ~1.5 тика.
- **Тихие повороты**: на сервер уходит поворот на блок, а камера остаётся где была.
  Поворот плавный, с ограничением скорости и **GCD-фиксом** (шаг кратен чувствительности мыши).
- Блок ставится, только когда **рейтрейс** с серверного поворота попадает в нужную грань.
- **MoveFix**: WASD пересчитываются под серверный yaw, движение совпадает с поворотом. Спринт пропадает сам,
  если поворот смотрит назад, как у настоящего игрока.
- **Раздельные скорости** для бриджа и клатча (как CustomBlockClutchRotationSpeeds у Augustus).
- **ExtraBlockSearch**: если прямо под ногами не за что зацепиться, ставит соседний блок и строит к себе.
- **Авто-выбор блоков** (самый большой стак в хотбаре) и возврат слота. Песок/гравий, сундуки и TNT не берёт.
  Не кликает по верстакам, сундукам и печкам, чтобы не открылся GUI.

## Управление
**J** — включить/выключить (клавиша меняется в «Управление → Scaffold»). `/sc`, `/scaffold` или `/cl` — статус.

| Команда | Что делает |
|---|---|
| `/sc toggle` / `on` / `off` | вкл/выкл |
| `/sc mode scaffold` | бридж + клатч (по умолчанию) |
| `/sc mode clutch` | только клатч при падении |
| `/sc speed 35 60` | скорость поворота в °/тик при бридже |
| `/sc clutchspeed 80 140` | скорость поворота в °/тик при клатче |
| `/sc fall 3` | клатчить, если под тобой пусто на N+ блоков |
| `/sc void` | клатчить только над войдом |
| `/sc search 2` | радиус поиска блоков (0–3) |
| `/sc reach 4.5` | дистанция до грани |
| `/sc switch` | авто-выбор блоков в хотбаре |
| `/sc switchback` | вернуть прежний слот |
| `/sc noswing` | не махать рукой на клиенте (пакет взмаха уходит) |
| `/sc delay 0` | задержка между блоками, тиков |
| `/sc keep 3` | сколько тиков держать поворот после блока, потом плавный возврат |
| `/sc hud` | надпись справа сверху: число блоков, ● пока работает |

Настройки — `.minecraft/config/scaffold.properties`.

**Под Polar:** держи `clutchspeed` ≤ ~150, `speed` ≤ ~70, `reach` ≤ 4.5. Резкие большие повороты — главное, за что ловят скаффолд.

## Сборка
`./gradlew build` (JDK 17) → `build/libs/Scaffold-1.8.9.jar`. Либо GitHub Actions собирает сам при каждом пуше
и выкладывает jar в релиз `scaffold-latest`.
