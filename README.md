# SafeWalk — Forge 1.8.9 (работает с LabyMod)

Не даёт сойти с края блока. Работает **только когда в руке блок и ты смотришь на блок, на котором стоишь**.

- **Sneak** (по умолчанию): у края сам жмёт **шифт** на 2–3 тика (0.1–0.15 с) и отпускает,
  как только под ногами появился блок. Останавливаешься совсем ненадолго.
- **Silent**: держит у края без приседа (пакет приседа не уходит, скорость не падает).

## Скачать
**[SafeWalk-1.8.9.jar](https://github.com/bolotina1448/esp/releases/download/safewalk-latest/SafeWalk-1.8.9.jar)**.
Положи в `.minecraft/mods` профиля Forge 1.8.9 с LabyMod. Можно ставить вместе с модом **Scaffold**, они совместимы.

## Управление
**K** — включить/выключить (клавиша меняется в «Управление → SafeWalk»). `/sw` или `/safewalk` — статус.

| Команда | Что делает |
|---|---|
| `/sw toggle` / `on` / `off` | вкл/выкл |
| `/sw mode sneak` | у края жмёт шифт (по умолчанию) |
| `/sw mode silent` | держит у края без приседа |
| `/sw ticks 2 3` | сколько тиков минимум держать шифт (1 тик = 0.05 с). Меньше — короче остановка |
| `/sw blocks` | только с блоком в руке (по умолчанию вкл) / всегда |
| `/sw look` | только когда смотришь на блок, на котором стоишь (по умолчанию вкл) / всегда |
| `/sw hud` | надпись «SafeWalk» справа сверху (голубая — работает, серая — нет блока в руке или смотришь не на блок под собой, ● — жмёт шифт) |

Настройки — `.minecraft/config/safewalk.properties`.

## Как работает
Перед каждым шагом мод считает, куда игра тебя сдвинет (тот же расчёт, что у ванилы), и проверяет,
не уводит ли сдвиг за край. В режиме Sneak у края он жмёт шифт: присед настоящий, сервер видит его как обычный,
ванила сама держит у края. Шифт отпускается через `ticks`, если край уже не грозит (поставил блок или перестал идти).
В режиме Silent сдвиг режется ванильным алгоритмом приседа с небольшим запасом. В прыжке, в воде, на лестнице и в полёте не работает.
Если ты сам приседаешь, край держит ванила.

С модом **Scaffold**: SafeWalk работает после MoveFix, то есть учитывает серверный поворот скаффолда.
Центр игрока у края всё равно выходит за блок, так что скаффолд успевает поставить блок под ноги.

## Сборка
`./gradlew build` (JDK 17) → `build/libs/SafeWalk-1.8.9.jar`. GitHub Actions собирает сам при каждом пуше
и выкладывает jar в релиз `safewalk-latest`.
